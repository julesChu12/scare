# 第一章 绪论

## 1.1 选题背景与意义

### 1.1.1 选题背景

随着我国人口老龄化进程的加快，社区养老服务需求日益增长。根据国家统计局数据，截至2024年底，我国60岁及以上人口已超过2.9亿，占总人口比例超过21%。北京市昌平区霍营街道作为典型的城市社区，老年人口数量逐年增加，养老服务需求呈现多样化特点。

当前社区养老服务存在以下问题：

1. **渠道分散**：需求上报依赖电话、微信群、线下登记等多种方式，缺乏统一入口，信息收集不全
2. **人工派单**：依靠人工整理和转发完成任务派发，响应不及时，效率低下
3. **责任不清**：缺乏明确的分发规则和责任界定，处理过程不透明，追溯困难
4. **空间脱节**：未结合社区站点和服务人员的空间分布，无法实现精准派单
5. **使用门槛**：老年人智能设备操作能力有限，需求提交不便

基于上述背景，有必要设计一个以社区站点为基本单元、基于地理围栏进行需求匹配和分发的服务信息平台，实现养老服务需求的集中管理和按地理范围的自动分发，从而提升社区养老服务的响应效率和管理水平。

### 1.1.2 选题意义

**理论意义**：将地理围栏技术应用于社区养老服务场景，探索基于地理位置信息的智能需求分发机制。通过射线法算法实现点在多边形的精确匹配，结合优先级排序和兜底机制，为地理信息技术在社区服务领域的应用提供实践案例。

**实践意义**：
- **降低使用门槛**：通过扫码方式提供统一需求入口，简化老年人操作流程
- **提升服务效率**：基于地理围栏规则实现需求自动分发，减少人工干预
- **增强服务透明度**：全流程状态跟踪，责任界定清晰
- **数据驱动决策**：积累服务数据，为资源配置和政策制定提供依据

## 1.2 国内外研究现状

### 1.2.1 社区养老服务信息化研究现状

发达国家在社区养老服务信息化方面起步较早。日本建立了较完善的长期护理保险制度，依托信息化手段实现服务需求精准对接，通过物联网设备实时监测老年人健康状态，并与社区服务平台联动。欧盟多国普遍采用"智慧养老"理念，通过物联网、大数据等技术提升社区养老服务效率，如德国的"居家养老智能监控系统"可实时监测老年人活动状态并自动触发应急响应。

近年来，我国高度重视养老服务信息化建设。国务院印发《"十四五"国家老龄事业发展和养老服务体系规划》，明确提出推进养老服务数字化转型。各地纷纷探索智慧养老服务平台建设，如上海市"综合为老服务平台"、北京市"养老服务管理信息系统"等。然而，现有平台多侧重于资源展示和预约功能，在基于地理位置的智能分发方面研究较少。

### 1.2.2 地理围栏技术应用研究现状

地理围栏（Geofencing）是一种基于位置服务的虚拟边界技术，广泛应用于物流配送、智慧交通、精准营销等领域。点在多边形判断是地理围栏的核心问题，常用算法包括射线法（Ray Casting）、回转数法等。射线法因实现简单、计算效率高而被广泛应用。

在公共服务领域，地理围栏技术已应用于城市管理、应急响应等场景。如某些城市利用地理围栏实现垃圾分类投放点的智能指引，疫情防控期间的区域管控等。但在社区服务场景，特别是养老服务的需求分发方面，地理围栏技术的应用探索尚不充分。

本设计将地理围栏技术与社区养老服务深度结合，通过自动化分发机制提升服务效率，为社区养老服务信息化提供新的技术路径。

## 1.3 开发目标

### 1.3.1 总体目标

设计并实现一个基于地理围栏的社区养老信息分发平台，实现养老服务需求的统一采集、按地理范围自动分发以及处理过程的全流程管理。系统以单街道（霍营街道）为试点范围，验证基于地理位置的需求分发机制在社区养老服务中的可行性。

### 1.3.2 具体目标

**功能目标**：
- 统一的需求提交入口，支持扫码快速进入，老年人可在3分钟内完成需求提交
- 基于地理围栏的需求自动分发，匹配时间小于50ms
- 完整的任务管理流程，支持任务认领、状态更新、完成反馈
- 细粒度的权限控制，支持四种角色的访问控制
- 多渠道通知机制，在关键节点自动发送通知

**性能目标**：
- 地理围栏匹配时间 < 50ms
- API平均响应时间 < 500ms
- 页面首屏加载时间 < 2秒
- 系统可用性 ≥ 99%

**技术目标**：
- 采用前后端分离架构，支持独立开发和部署
- 使用JWT实现双端认证，确保接口安全
- 采用自定义RBAC模型实现细粒度权限控制
- 支持PWA特性，提供离线访问能力

本文共分为七章：
