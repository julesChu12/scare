## 导出步骤（使用 draw.io）

### 方法一：draw.io 桌面应用

1. 打开 draw.io 应用
2. **文件 → 打开**，选择上述 drawio 文件
3. **文件 → 导出为 → PNG**
4. 设置：
   - **边距**: 0
   - **分辨率**: 300 dpi（推荐）
   - **透明背景**: 取消勾选
   - **包含图表的副本**: 取消勾选
5. 点击 **导出**，保存到 `paper/附件/diagrams/png/` 目录

### 方法二：draw.io 在线版（https://app.diagrams.net/）

1. 访问 https://app.diagrams.net/
2. **打开现有图表**，选择上述 drawio 文件
3. **文件 → 导出为 → PNG**
4. 设置分辨率后下载
5. 将下载的 PNG 文件移动到 `paper/附件/diagrams/png/` 目录

## 导出设置建议

| 设置项 | 推荐值 | 说明 |
|--------|--------|------|
| 分辨率 | 300 dpi | 学术论文标准，保证打印质量 |
| 边距 | 0 px | 避免多余白边 |
| 缩放 | 100% | 保持原始尺寸 |
| 透明背景 | 否 | 白色背景更适合论文打印 |
| 抗锯齿 | 启用 | 平滑线条和文字 |
