## 🔧 修复操作步骤

### 修复 1：第六章标题样式（heading 1）

**问题**：第六章"系统测试"内容存在但使用 NO_STYLE 而非 heading 1 样式，导致目录中缺少第六章。

**操作步骤**：
1. 打开 `昌平区霍营街道社区养老信息分发平台_毕业论文_fixed.docx`
2. 使用 `Ctrl + F` 搜索关键字：`第六章 系统测试`
3. 找到该行：`第六章 系统测试：给出测试用例和测试结果`
4. **选中该行文本**
5. 在"开始"选项卡中，找到"样式"区域
6. 点击样式下拉框，选择 **"标题 1"**（或 Heading 1）
7. 确认文本已变为醒目的标题格式

**验证方法**：
- 滚动到文档开头，查看目录页
- 确认"第六章 系统测试"已出现在目录中

---

### 修复 2：添加 ABSTRACT 标题（heading 2）

**问题**：英文摘要有内容但缺少 "ABSTRACT" 标题。

**操作步骤**：
1. 使用 `Ctrl + F` 搜索关键字：`KEY WORDS:`
2. 找到该行：`KEY WORDS: Community Elderly Care, Geofencing, Ray Casting Algorithm, Go Language, Vue.js, RBAC`
3. **将光标移到该段落的最前面**
4. 按 `Enter` 键创建一个新段落
5. 在新段落中输入：`ABSTRACT`
6. **选中 "ABSTRACT" 文本**
7. 在"开始"选项卡中，找到"样式"区域
8. 点击样式下拉框，选择 **"标题 2"**（或 Heading 2）
9. 确认 "ABSTRACT" 显示为标题格式

**验证方法**：
- 滚动到文档开头，查看目录页
- 确认 "ABSTRACT" 出现在目录中
- 确认 "ABSTRACT" 位于 "关键词" 之前

---

### 修复 3：每章另起一页（分页符）

**问题**：所有章标题的 `pageBreakBefore` 均为 `False`，章节应该另起一页。

**操作步骤**：
1. 使用 `Ctrl + F` 搜索关键字：`第一章 绪论`
2. **选中 "第一章 绪论" 文本**
3. 右键点击文本
4. 选择：**段落 → 换行和分页 → 分页符 → 下一页**
5. 确认 "第一章 绪论" 已移到新页面顶部
6. 对以下章节重复步骤：
   - 第二章 相关理论与技术
   - 第三章 需求分析
   - 第四章 系统概要设计
   - 第五章 系统详细设计与实现
   - 第七章 总结
   - 参考文献
   - 致谢
   - 附录

**技巧**：
- 使用 `Ctrl + F3` 查找下一个（重复上一次搜索）
- 确保每个章节标题都在新页面的第一行

**验证方法**：
- 在打印预览中查看
- 每章都应该从新页面开始
- 页码应该连续（1, 2, 3...）

---

### 修复 4：验证参考文献正文标注格式

**问题**：需要确认正文中的引用标注是右上角上标格式。

**操作步骤**：
1. 使用 `Ctrl + F` 搜索关键字：`[1]`
2. 检查搜索结果中的 `[1]` 是否为**上标格式**
3. 如果是普通文本，需要修改：
   - 删除普通格式的 `[1]`
   - 插入上标数字：按 `Ctrl + Shift + =` 输入 `¹`
   - 或者：插入 → 符号 → 选择上标数字 `¹`
4. 重复检查所有引用标注（约40处）

**正确格式示例**：
- 如图3-1 现有业务流程图[1]所示
- 根据文献[2]的研究...
- 采用Go语言[6]和Gin框架[7]构建...

**验证方法**：
- 正文中的 `[1]` `[2]` 等应显示为上标 `¹` `²`
- 参考文献列表中的编号与正文标注一一对应

## ⚠️ 常见问题

### Q1: 设置样式后没有变化？
A: 尝试清除格式：选中文本 → 清除所有格式 → 重新设置样式

### Q2: 分页符设置无效？
A: 确保选中整个标题行（包括段落标记），而不是部分文本

### Q3: draw.io 导出的图片太大？
A: 调整画布大小后再导出，或者在导出时调整分辨率

### Q4: 更新目录后第六章仍不显示？
A: 尝试更新整个文档的域代码：Ctrl+A → F9（全选 → 更新域）
