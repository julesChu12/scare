# sCare 快速开通系统 - 实现总结

## 项目概述

为 sCare 社区养老服务平台实现了完整的"扫码即用"快速开通系统，包括前端框架和后端 API。

## 一、前端实现（Vue 3 + TypeScript + PWA）

### 1.1 项目配置
- ✅ `package.json` - Vue 3.4 + TypeScript + Pinia + Element Plus + PWA
- ✅ `vite.config.ts` - Vite 5.0 + PWA插件 + API代理
- ✅ `tsconfig.json` - TypeScript 配置
- ✅ `index.html` - PWA meta标签配置

### 1.3 核心功能
- **路由系统**: 6个页面路由 + 登录守卫
- **状态管理**: Token Store + User Store
- **API 封装**: Axios 拦截器 + 统一错误处理
- **PWA 支持**: 离线缓存 + 可安装 + 离线API缓存
- **UI 组件**: Element Plus 完整集成

### 1.4 快速开通流程（核心）
1. 用户扫描服务站二维码（携带 station_id）
2. 跳转到快速开通页面
3. 填写信息：手机号 + 验证码 + 姓名 + 身份证 + 地址 + 服务类型
4. 提交后自动完成：注册账号 + 登录系统 + 创建服务请求
5. 跳转到服务详情页

## 二、后端实现（Go + Gin + GORM）

### 2.1 新增服务层（3个文件）

#### `internal/service/sms_service.go`
- 短信验证码服务（Redis 存储）
- 频率限制：1分钟1次，每天10次
- 开发环境：控制台打印验证码
- 生产环境：返回错误（需要 SMS 服务资质）

**核心方法**:
```go
SendCode(phone string) error           // 发送验证码
VerifyCode(phone, code string) error   // 验证验证码
```

**Redis Keys**:
```
sms_code:{phone}           - 验证码（TTL: 300s）
sms_rate:{phone}:minute    - 分钟级锁（TTL: 60s）
sms_rate:{phone}:daily     - 每日计数（TTL: 86400s）
```

#### `internal/service/auth_service.go` (扩展)
新增快速开通方法：

```go
QuickStart(input QuickStartInput) (*QuickStartResult, error)
```

**事务流程**:
1. 验证短信验证码
2. 检查手机号是否已注册
3. 在事务中：
   - 创建或获取用户
   - 创建或更新客户档案
   - 创建服务请求
   - 创建任务分配
4. 生成 C端 JWT Token

#### `internal/service/geocode_service.go`
地址解析服务（高德地图 API）

```go
Geocode(address string) (*GeocodeResult, error)
```

- 无 API Key：返回默认经纬度（北京天安门）
- 有 API Key：调用高德地图 API
- 返回：经度、纬度、格式化地址

### 2.2 新增处理器（2个文件）

#### `internal/handler/c_auth_handler.go` (扩展)
新增3个方法：

```go
SendCode(c *gin.Context)      // POST /api/v1/c/auth/send-code
QuickStart(c *gin.Context)    // POST /api/v1/c/auth/quick-start
CheckToken(c *gin.Context)    // GET  /api/v1/c/auth/check
```

#### `internal/handler/c_profile_handler.go` (新建)
```go
UpdateProfile(c *gin.Context)  // PUT  /api/v1/c/profile
Geocode(c *gin.Context)        // POST /api/v1/c/geocode
```

### 2.3 路由配置 (`internal/handler/routes.go`)

#### 白名单路由（无需认证）
```go
POST /api/v1/c/auth/send-code      // 发送验证码
POST /api/v1/c/auth/quick-start    // 快速开通
POST /api/v1/c/auth/login          // 密码登录
POST /api/v1/c/auth/refresh        // 刷新Token
POST /api/v1/c/geocode             // 地址解析
```

#### 需要认证（无需权限）
```go
GET  /api/v1/c/auth/me     // 获取当前用户
GET  /api/v1/c/auth/check  // 检查Token（预填充）
POST /api/v1/c/auth/logout // 登出
```

#### 需要认证 + 权限
```go
PUT  /api/v1/c/profile              // 更新个人资料
POST /api/v1/c/requests             // 创建服务请求
GET  /api/v1/c/requests             // 查看我的请求
GET  /api/v1/c/requests/:id         // 请求详情
POST /api/v1/c/requests/:id/cancel  // 取消请求
```

## 四、技术亮点

### 4.1 事务一致性
快速开通 API 使用 GORM 事务，确保原子性：
- 用户创建 → 档案创建 → 请求创建 → 任务分配
- 任何步骤失败，全部回滚

### 4.2 PWA 离线支持
- Service Worker 自动缓存静态资源
- API 请求使用 NetworkFirst 策略
- 离线可查看历史服务记录

### 4.3 验证码安全
- Redis 存储，5分钟过期
- 验证后自动删除
- 频率限制防止暴力破解

### 4.4 Token 自动注入
前端 Axios 拦截器自动添加 Token：
```typescript
client.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})
```

### 4.5 401 自动跳转
```typescript
client.interceptors.response.use(
  response => response.data,
  error => {
    if (error.response?.status === 401) {
      localStorage.removeItem('token')
      window.location.href = '/login'
    }
  }
)
```

## 八、注意事项

### 8.1 SMS 验证码
- 开发环境：验证码打印到控制台
- 生产环境：需要接入真实 SMS 服务商（需要资质）

### 8.2 地址解析
- 当前配置：无 API Key，返回默认经纬度
- 生产环境：需要配置高德地图 API Key

### 8.3 安全性
- 验证码5分钟过期
- 频率限制：1分钟1次，每天10次
- Token 存储在 localStorage（可考虑 httpOnly Cookie）

### 8.4 数据库
- 无需额外迁移，使用现有表结构
- users 表：phone 字段唯一索引
- customer_profiles 表：user_id 唯一索引
- service_requests 表：request_no 唯一索引
