# sCare 开发环境启动指南

## 快速开始

### 1. 启动环境依赖

使用 Docker Compose 启动 MySQL 和 Redis:

```bash
# 启动服务
docker-compose up -d

# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs -f
```

**首次启动说明**:
- MySQL 会自动执行 `database/schema/schema.sql` 和 `database/seeds/seed.sql`
- 初始化完成后即包含测试数据(12个用户、3个站点、5个围栏)

### 2. 验证数据库初始化

```bash
# 连接到 MySQL
docker exec -it scare_mysql mysql -uscare_user -pscare_pass scare_db

# 检查表和数据
SHOW TABLES;
SELECT COUNT(*) FROM users;
SELECT COUNT(*) FROM service_stations;
SELECT COUNT(*) FROM service_zones;

# 退出
EXIT;
```

### 3. 安装 Air 热加载工具

```bash
# 安装 Air (如果还没有安装)
go install github.com/cosmtrek/air@latest

# 验证安装
air -v
```

### 4. 安装 Go 依赖

```bash
cd backend
go mod download
go mod tidy
```

### 5. 启动后端服务 (热加载模式)

```bash
# 在项目根目录执行
air

# 或者手动指定配置文件
air -c .air.toml
```

服务将在 `http://localhost:8080` 启动，修改任何 `.go` 文件后会自动重新编译和重启。

```bash
# 用工作人员账号登录
curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "phone": "13800000004",
    "password": "Test@123"

# 查看任务池 (使用工作人员的 token)
```

#### 6.6 认领任务

```bash
# 认领任务 ID 为 1 的任务
curl -X POST http://localhost:8080/api/v1/tasks/1/claim \
  -H "Authorization: Bearer STAFF_TOKEN"
```

#### 6.7 完成任务

```bash
# 完成任务
curl -X POST http://localhost:8080/api/v1/tasks/1/complete \
  -H "Authorization: Bearer STAFF_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "images": ["/uploads/2026/01/task1_photo1.jpg"]
  }'
```

## P0 核心 API 列表

所有 API 路径前缀: `/api/v1`

### 认证相关
- `POST /auth/login` - 登录
- `GET /auth/me` - 获取当前用户信息 (需要 JWT)

### 需求管理
- `POST /requests` - 提交需求 (elderly/family 角色)
- `GET /requests/:id` - 需求详情 (需要 JWT + 权限)

### 任务管理
- `GET /tasks/pool` - 站点任务池 (staff/station_manager 角色)
- `GET /tasks/my` - 我的任务列表 (staff 角色)
- `POST /tasks/:id/claim` - 认领任务 (staff 角色)
- `POST /tasks/:id/complete` - 完成任务 (staff 角色)

### 基础数据
- `POST /stations` - 创建站点 (admin 角色)
- `POST /zones` - 创建地理围栏 (admin 角色)

## 开发工具

### 热加载

Air 会监控以下文件变化并自动重启:
- `backend/**/*.go` (所有 Go 源文件)
- `backend/**/*.html` (模板文件)

排除的目录:
- `tmp/` (构建输出)
- `vendor/` (第三方依赖)
- `database/` (数据库脚本)
- `claudedocs/` (文档)

### 日志

开发模式下日志输出到:
- 控制台 (标准输出)
- `logs/app.log` 文件

### 数据库管理

```bash
# 重置数据库
docker-compose down -v  # 删除所有数据
docker-compose up -d    # 重新启动并初始化

# 仅重启 MySQL
docker-compose restart mysql

# 进入 MySQL 容器
docker exec -it scare_mysql bash
```

### Redis 管理

```bash
# 连接 Redis CLI
docker exec -it scare_redis redis-cli -a scare_redis_pass

# 查看所有键
KEYS *

# 清空所有数据
FLUSHALL
```

## 常见问题

### Q1: Air 启动失败提示找不到 air 命令?

```bash
# 确保 GOPATH/bin 在 PATH 中
export PATH=$PATH:$(go env GOPATH)/bin

# 或者重新安装 Air
go install github.com/cosmtrek/air@latest
```

### Q2: 数据库连接失败?

检查 `.env` 文件中的数据库配置是否正确，确保 Docker 服务已启动:

```bash
docker-compose ps
```

### Q3: Casbin 权限检查失败?

确保 `backend/configs/casbin_model.conf` 和 `backend/configs/policy.csv` 文件存在且路径正确。

### Q4: JWT token 无效?

确保 `.env` 中的 `JWT_SECRET` 已设置且不为空。

### Q5: 地理围栏匹配失败?

检查提交的坐标是否在测试围栏范围内:
- 霍营站A区: 华龙苑北里附近 (40.05, 116.38)
- 霍营站B区: 霍营中心区域 (40.06, 116.37)
- 龙泽站: 龙泽园区域 (40.07, 116.35)
