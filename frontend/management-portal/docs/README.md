## 技术栈

- Vue 3 + TypeScript + Vite + Pinia
- Element Plus UI 组件库
- Casbin.js RBAC 权限

## 当前实现

1. **登录 + 基础布局**: 登录页与基础布局已落地
2. **任务管理（staff）**: 任务池、我的任务、任务详情
3. **API 接入**: 任务池/我的任务/任务详情接口调用
4. **权限基础**: 登录鉴权 + 角色路由守卫（基于 meta.roles）

## 规划/待完成

- **Casbin 资源级权限**: `checkPermission` 尚未落地，指令/Hook 已预留
- **站点负责人/管理员功能**: 任务分配、人员/站点管理
- **围栏管理**: 地理围栏绘制与编辑
- **数据统计**: ECharts 数据可视化

## 开发优先级

1. **Phase 1**: 权限系统（角色级已完成，Casbin 资源级待接入）
2. **Phase 2**: 基础布局和导航（已完成）
3. **Phase 3**: 核心业务界面（任务相关已完成，其它待补）
4. **Phase 4**: 高级功能（地图集成、数据可视化）
