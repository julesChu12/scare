## 技术栈

- Vue 3 + TypeScript + Vite + Pinia
- Element Plus UI 组件库（当前实现）
- PWA 支持（已配置）

## 当前实现

1. **快速开通**: 扫码入口 + 表单提交
2. **登录**: 密码登录
3. **我的服务**: 列表与详情
4. **首页与个人资料**
5. **PWA 基础配置**: Service Worker 由 Vite PWA 生成

## 规划/待完成
