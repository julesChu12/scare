# C端 UI 交互草图与层级结构 (Wireframes)

**状态**：已确认
**最后更新**：2026-01-20
**描述**：本文档包含 C 端应用的页面层级结构（Hierarchy）及 ASCII 风格的 UI 线框图（Wireframes），用于指导前端开发。

---

## 模块 A：入口与认证 (Entry & Auth)
*负责用户的接入、身份识别和落地引导。*

### 层级结构
*   **A1: 登录页 (LoginView)** - *一级页面*
    *   (无子页面)

## 模块 B：核心业务 (Core Business)
*承载用户的主要操作：查看信息、发起服务需求。*

### 层级结构
*   **B1: 首页 (HomeView)** - *一级页面*
    *   跳转 -> **B2: 申请表单页**
    *   跳转 -> **B3: 全部服务列表页**
*   **B2: 申请表单页 (RequestView)** - *二级页面 (兼扫码落地页)*
    *   提交成功 -> 返回 B1: 首页
*   **B3: 全部服务列表 (ServiceListView)** - *二级页面*
    *   点击服务 -> 跳转 B2: 申请表单页

### UI 草图 (B1 首页)
```text
+-------------------------------+
|  sCare            [我的] -> C1|
+-------------------------------+
|  [ Banner: 防诈骗/通知... ]   |
+-------------------------------+
|  🛠️ 服务 (金刚区)             |
|  [🍚助餐] [🧹保洁] [➕更多]->B3|
|   | (点击跳转 B2)             |
+-------------------------------+
|  📰 资讯流                    |
|  [🔈] 医保报销指南        [图]|
+-------------------------------+
```

### UI 草图 (B2 申请表单页)
```text
+-------------------------------+
| < 返回      申请助餐          |
+-------------------------------+
|  1. 联系人 (登录自动填/手动)  |

|  3. 备注                      |

+-------------------------------+
```

## 模块 C：个人中心 (User Center)
*负责个人数据管理、订单追踪及紧急功能。*

### 层级结构
*   **C1: 个人中心 (ProfileView)** - *一级页面*
    *   跳转 -> **C2: 需求列表页**
    *   跳转 -> **C3: 设置页**
    *   交互 -> **紧急呼叫 (拨号)**
*   **C2: 需求列表页 (OrderListView)** - *二级页面*
    *   点击卡片 -> C2-1: 订单详情页 (OrderDetail)
*   **C3: 设置页 (SettingsView)** - *二级页面*

### UI 草图 (C1 个人中心)
```text
+-------------------------------+
| < 返回      个人中心          |
+-------------------------------+
|  [头像] 张建国                |
|  📍 幸福小区 1-201            |
+-------------------------------+
|  📋 功能                      |
|  我的需求列表 (-> C2)       > |
|  设置 (-> C3)               > |
+-------------------------------+
|                               |
|      (防误触留白区)           |
|                               |
+-------------------------------+
|  🚨 紧急呼叫值班室 (红色)     |
+-------------------------------+
```
