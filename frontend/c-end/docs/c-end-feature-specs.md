# C端功能详细设计规格说明书 (v1.2)

**状态**：已确认
**最后更新**：2026-01-20
**适用端**：C端 (Mobile Web / PWA)

---

## 0. 访问入口逻辑 (New)

### 0.1 扫码访问 (Landing)
*   **场景**：用户扫描社区张贴的二维码。
*   **链接格式**：`/request?type={serviceType}&source=qrcode`
*   **逻辑**：直接落地到 **服务申请页 (RequestView)**。
*   **权限**：允许匿名访问和提交。若检测到未登录，表单项全空并提示“登录后可自动回填”。

---

## 1. 首页 (HomeView)

### 1.1 页面布局
1.  **顶部导航**：左侧应用名，右侧个人中心入口。
2.  **Banner 区域**：轮播社区动态。
3.  **核心服务区 (金刚区)**：高频服务入口。
4.  **社区资讯流 (Feed)**：带语音播报的新闻列表。

---

## 2. 服务申请页 (RequestView)

### 2.1 匿名与登录兼容
*   **逻辑**：
    *   URL 携带 `type` 参数。
    *   已登录：回填姓名、电话、地址。
    *   未登录：展示空表单，地址栏提供定位按钮。
*   **提交后逻辑**：
    *   匿名提交成功后，提示框下方增加“登录/注册”引导，方便下次使用。

---

## 3. 登录页面 (LoginView) (New)

### 3.1 设计原则
*   **极简流程**：手机号 + 短信验证码。
*   **视觉**：超大输入框，超大“获取验证码”点击区。

### 3.2 交互逻辑
1.  输入手机号（校验 11 位）。
2.  点击获取验证码 -> 60s 倒计时。
3.  输入验证码 -> 点击登录。
4.  **重定向**：登录成功后，跳转回 `redirect` 参数指向的页面（如：扫码进来的表单页）。

---

## 4. 个人中心 (ProfileView)

### 4.1 核心功能
1.  **用户信息**：显示/修改个人基础资料。
2.  **我的需求列表**：查看已提交申请的状态。
3.  **紧急呼叫 (置底)**：红色大按钮，一键拨号值班室。
